1. システム概要

本システムは、LOCABLE における図面管理・LOD（Level of Detail）管理・変更影響管理を行うMVPシステムです。 案件管理システムではなく、案件（プロジェクト）を切り替えながら図面を管理するためのツールとして設計されています。

項目内容
フロントエンドVite + React + TypeScript
ホスティングCloudflare Pages
APICloudflare Pages Functions（functions/api）
DBCloudflare D1（migrations/）
認証Cloudflare Access
ファイル本体Google Drive（DBにはURLのみ保持）

2. 必要環境

  • Node.js（npm が使用できること）
  • Cloudflare アカウント（Pages / D1 / Access を利用）
  • Google Drive（図面ファイルの保管先）

3. インストールと起動

リポジトリを取得した後、依存パッケージをインストールし、開発サーバーを起動します。

npm install
npm run dev

本番ビルドは以下のコマンドで作成します。

npm run build

4. Cloudflare Access 認証

本システムへのアクセスは Cloudflare Access によって保護されます。利用するユーザーは管理者から Cloudflare Access のアクセス許可を受ける必要があります。詳細な設定はCloudflareダッシュボードの Access ポリシーを参照してください。

5. D1マイグレーション

D1データベースへスキーマを適用するには、用途に応じて以下のコマンドを使用します。

# ローカル開発DBへ適用
npm run db:migrate:dev

# 開発用リモートD1へ適用
npm run db:migrate:remote:dev

# 本番用リモートD1へ適用
npm run db:migrate:remote:prod

wrangler.toml の database_id は、実際のD1データベース作成後に 正しい値へ差し替えてください。

6. Google Drive 連携

図面ファイルの本体は Google Drive に保管し、データベースにはそのファイルへのURLのみを保持します。 図面登録時に Google Drive 上のファイルへのリンクを設定してください。

7. 基本的な使い方

ダッシュボード

進行中プロジェクト数、LOD不足図面数、変更影響あり図面数、期限超過数などの概況を確認できます。

図面管理

案件（プロジェクト）を選択し、図面の一覧表示・カード表示・検索・新規登録・詳細確認を行います。

変更項目

変更理由・内容・影響度を登録し、関連する図面と紐づけて影響を管理します。

設定

フェーズ × 図面種別ごとの必要LOD（必須・任意・不要）を管理します。

8. よくある質問

Q. ログインできない場合は？

A. Cloudflare Access の許可設定がされているかシステム管理者に確認してください。

Q. 図面ファイル本体はどこに保存されますか？

A. ファイル本体は Google Drive に保管され、本システムにはリンクURLのみが保存されます。
