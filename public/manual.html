1. システム概要

本システムは、LOCABLE における図面管理・LOD（Level of Detail）管理・変更影響管理を行うMVPシステムです。 案件管理システムではなく、案件（プロジェクト）を切り替えながら図面を管理するためのツールとして設計されています。

項目内容
フロントエンドVite + React + TypeScript
ホスティングCloudflare Pages
APICloudflare Pages Functions（functions/api）
DBCloudflare D1（migrations/）
認証Cloudflare Access
ファイル本体Google Drive（DBにはURLのみ保持）

2. 必要環境

  • Node.js（npm が使用できること）
  • Cloudflare アカウント（Pages / D1 / Access を利用）
  • Google Drive（図面ファイルの保管先）

3. インストールと起動

リポジトリを取得した後、依存パッケージをインストールし、開発サーバーを起動します。

npm install
npm run dev

本番ビルドは以下のコマンドで作成します。

npm run build

4. Cloudflare Access 認証

本システムへのアクセスは Cloudflare Access によって保護されます。利用するユーザーは管理者から Cloudflare Access のアクセス許可を受ける必要があります。詳細な設定はCloudflareダッシュボードの Access ポリシーを参照してください。

5. D1マイグレーション

D1データベースへスキーマを適用するには、用途に応じて以下のコマンドを使用します。

# ローカル開発DBへ適用
npm run db:migrate:dev

# 開発用リモートD1へ適用
npm run db:migrate:remote:dev

# 本番用リモートD1へ適用
npm run db:migrate:remote:prod

wrangler.toml の database_id は、実際のD1データベース作成後に 正しい値へ差し替えてください。

6. Google Drive 連携

図面ファイルの本体は Google Drive に保管し、データベースにはそのファイルへのURLのみを保持します。 図面登録時に Google Drive 上のファイルへのリンクを設定してください。

7. 基本的な使い方

ダッシュボード

進行中プロジェクト数、LOD不足図面数、変更影響あり図面数、期限超過数などの概況を確認できます。

図面管理

案件（プロジェクト）を選択し、図面の一覧表示・カード表示・検索・新規登録・詳細確認を行います。

変更項目

変更理由・内容・影響度を登録し、関連する図面と紐づけて影響を管理します。

設定

フェーズ × 図面種別ごとの必要LOD（必須・任意・不要）を管理します。

右パネル：図面一覧

図面追加フォーム

図面詳細モーダル

図面番号または図面名をクリックすると以下の情報を確認できます。

  • 基本情報：図面種別、必要LOD、現在LOD、LOD判定
  • 進捗情報：ステータス、ロック状態、承認状態、担当者、確認期限、確定期限
  • Driveリンク：最新PDF、作業元ファイルへのリンク（Google Drive上のファイル）
  • 関連変更項目：この図面に紐づく変更項目（変更理由・変更内容・同期状態）の一覧
  • 備考：備考テキストと次アクション

11. 画面詳細：設定

フェーズ × 図面種別ごとに必要なLOD（Level of Detail）を管理する画面です。図面登録時のLOD自動判定の基準になります。

列名説明
フェーズコードプロジェクトの「フェーズ」欄と一致させるコード（例：基本設計）
図面種別図面登録時の「図面種別」欄と一致させる種別名（例：平面図）
必要LOD0〜6の数値。そのフェーズ・種別における到達すべき詳細度
必要性必須／任意／不要
  • ルールを追加：新しい行を追加し、フェーズコード・図面種別・必要LOD・必要性を入力します。
  • 保存：入力したルールをまとめて保存します。
  • 削除：各行右端のリンクで該当ルールを削除します。
  • セットアップマニュアルを開く：このマニュアルを新しいタブで開きます。

ここで登録したルールは、図面管理画面で図面を新規追加した際に「プロジェクトの現フェーズ」×「入力した図面種別」で自動的に検索され、 必要LOD・LOD判定・次アクションの自動計算に使われます。先にプロジェクトを作成・運用する前に、このページでルールを整備しておくことを推奨します。

12. 用語・項目の意味

LOD判定

判定条件次アクション
不要必要LOD = 0着手しない
不足現在LOD < 必要LODLODを上げる
OK現在LOD = 必要LOD確認・ロック判断
過剰現在LOD > 必要LODこれ以上触らない

必要性

必須／任意／不要の3段階で、その図面が当該フェーズで必要かどうかを示します。

ロック状態

未ロック／承認ロック／施工ロック／竣工ロックなど。図面が確定し変更してはならない段階に入ったことを示します。

変更項目の影響度

高／中／低の3段階で、変更が図面に与える影響の大きさを示します。

変更項目の状態

未確認（登録時の初期状態）／対応済／却下。

13. よくある質問

Q. ログインできない場合は？

A. Cloudflare Access の許可設定がされているかシステム管理者に確認してください。

Q. 図面ファイル本体はどこに保存されますか？

A. ファイル本体は Google Drive に保管され、本システムにはリンクURLのみが保存されます。
